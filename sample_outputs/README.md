# Sample Outputs

The canonical demonstration output files for this repository are located in `/sample_outputs`. These files are fake demonstration outputs prepared only to show reviewable support-material shapes, including normalized transactions, fair-value support, journal-entry preparation, reconciliation status, Form 1099-DA readiness, Form 8949 reconciliation, and audit evidence package summaries. They are not final filings, audit opinions, accounting conclusions, legal conclusions, tax advice, or compliance certifications.

They are intended only as inspectable examples for professional review and implementation planning. The files in this folder use fake demonstration data and must not include real client data, real taxpayer data, real wallet data, real transaction hashes, or real financial records.
