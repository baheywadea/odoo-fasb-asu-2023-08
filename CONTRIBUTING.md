# Contributing

Thank you for your interest in this project.

This repository welcomes professional feedback and contributions from:

- Odoo developers
- ERP consultants
- Accountants and CPAs
- Fintech professionals
- Digital asset compliance specialists

## Ways to Contribute

You can help by:

1. Reviewing the accounting workflow
2. Testing the Odoo module
3. Suggesting FASB ASU 2023-08 improvements
4. Reviewing security assumptions
5. Adding documentation or screenshots
6. Opening issues for missing features
7. Submitting pull requests

## Professional Feedback

If you are an accountant, CPA, auditor, ERP consultant, or fintech professional, please share your feedback in GitHub Discussions:
